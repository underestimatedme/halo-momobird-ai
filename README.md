# halo-momobird-ai

把 Halo 的公开文章同步到 MomoBird 控制台的项目里，让这些文章可以在「问答调试」和网站问答助手里被提问、被引用；也可以把 MomoBird 问答助手挂到站点每个页面，并在文章页播放 AI 播客。

本插件属于 MomoBird 专业版功能。创建第一个项目时自动开始 14 天试用；企业空间按企业套餐。

Halo 是常驻的动态站点，所以同步是**持续的**：文章发布、修改、下线、删除、改可见性时几秒内就会推送或撤下；另外每天凌晨做一次全量对账，兜住漏掉的事件。

## 功能

- 同步公开文章：已发布、可见性为「公开」、不在回收站、没有排除标记的文章。草稿、定时发布还没到时间的、内部或私有的文章不会同步。**页面（独立页面）不同步。**
- 文章的发布、修改、下线、删除、可见性变化都会触发同步，不论哪种事件，插件都会重新读一次这篇文章：符合条件就推送，不符合（或者已经不存在了）就从 MomoBird 撤下。
- 每天一次全量对账，插件启动一分钟后也会对账一次；后台「工具 → MomoBird」页面可以随时手动对账。
- 同步失败不会影响站点：推送发生在插件自己的后台线程里，访客看页面、你在后台写文章都不会等它。
- 可选：在站点每个页面显示 MomoBird 问答助手；在文章页显示播客播放器（文章生成过播客才会出现）。

## 环境要求

- Halo 2.17 或更高版本（已在 2.17 和 2.27 上验证）
- Halo 服务器可以访问 `https://api.valley.atlaspaces.com`
- Halo 的**外部访问地址**已经设置，并且和 MomoBird 来源的网站地址同源（见下）

## 安装

1. 在 MomoBird 控制台（https://momobird.atlaspaces.com）打开或新建一个项目，进入「知识 → 连接博客 → 博客 / 论坛」，平台选 **Halo**，网站地址填你的 Halo 外部访问地址（协议和域名，含端口，不含路径）。
2. 复制页面上显示的**连接密钥**（以 `mbk_` 开头，只显示这一次）。
3. 下载插件：`https://momobird.atlaspaces.com/downloads/halo-momobird-ai-0.1.0.jar`。
4. 在 Halo 后台打开「插件 → 安装」，选择「本地上传」，选中下载的 jar 文件。
5. 安装完成后在插件列表里点「启用」。
6. 以**超级管理员**身份打开「插件 → MomoBird AI → 设置 → 连接」，在「连接密钥」一栏新建一个密钥，把第 2 步复制的连接密钥粘贴进去，再点「保存」：
   - Halo 2.23 及更新版本（例如 2.27）：点「连接密钥」右侧的 ⊕，在弹出的「创建密钥」里 Key 已经填好 `key`，把连接密钥粘贴到 Value，点「保存」；
   - Halo 2.17 到 2.22：在「连接密钥」的输入框里粘贴连接密钥，点下拉里的「根据输入的文本创建新密钥」。

   连接密钥存放在 Halo 的「密钥」（Secret）里，插件设置只记密钥的名字（形如 `secret-xxxxx`），见下面「连接密钥存放在哪里」。
7. 打开「工具 → MomoBird」，点「测试连接」，确认项目、来源、套餐和站点地址检查都正常；然后点「立即全量同步」。

文件名带版本号，升级时在「插件」列表里选择新的 jar 升级即可。

## 设置

在「插件 → MomoBird AI → 设置」里，分三组：

**连接**

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| Base URL | `https://api.valley.atlaspaces.com` | MomoBird 接口地址，必须是 HTTPS，一般不用改。本地联调可以用 `http://localhost` 或 `http://127.0.0.1` |
| 连接密钥 | 空 | 选择或新建一个 Halo 密钥（Secret），它的 `key` 一项是 MomoBird 控制台知识源页面生成的连接密钥（以 `mbk_` 开头）。只有超级管理员能新建、查看和选择密钥 |

**问答助手**

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| 在站点上显示问答助手 | 关 | 打开后，访客可以在每个页面右下角（或左下角）向文章提问。第一次同步完成并建好索引后才会真正显示 |
| 按钮位置 | 右下 | 右下或左下 |

**播客**

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| 在文章页显示播客播放器 | 开 | 文章同步到 MomoBird 后，访客可以直接收听文章的 AI 播客 |
| 显示文字稿 | 关 | 在播放器下方显示播客的文字稿 |

**连接密钥存放在哪里。** Halo 允许拥有「插件查看」权限的用户读取插件设置，所以连接密钥**不放在插件设置里**：设置只保存一个 Halo 密钥（Secret）的名字，密钥本身存在 Halo 的「密钥」里。Halo 自带的角色模板都不包含读取密钥的权限，只有超级管理员能通过 Halo 的接口看到它。因此：

- 只有超级管理员能新建、更换连接密钥。拥有「插件管理」权限但不是超级管理员的管理员可以改其他设置、使用「工具 → MomoBird」页面，但设置页里的「连接密钥」对他们显示为无权限。
- 更换密钥：在「连接密钥」里编辑现有密钥的 `key` 一项（新版点编辑图标；2.17 到 2.22 点右侧的齿轮「管理密钥」），或者新建一个密钥再选中它，最后点「保存」。
- 卸载插件不会删除这个密钥，需要的话在「连接密钥」的密钥管理里删掉。

插件的任何接口、后台页面、日志和前台页面都不会出现密钥原文，连 `mbk_` 前缀也不会打印；错误信息里如果带出了形似密钥的字符串，会先抹掉再显示。

设置修改后，下一次同步或下一次页面渲染就会生效，不用重启插件。

## 外部访问地址必须设置，并且和 MomoBird 来源同源

文章的链接是「Halo 外部访问地址 + 文章路径」，MomoBird 只接受和来源网站地址**同源**（协议、域名、端口一致，注意 `www` 和 http/https）的链接。所以：

- 较新的 Halo（例如 2.27）：在后台「系统设置 → 基本设置 → 外部访问地址」填写网站地址。
- Halo 2.17 等旧版本：后台没有这一项（外部访问地址只读启动参数），要在 Halo 的启动参数或配置文件里设置 `halo.external-url`，例如 `--halo.external-url=https://blog.example.com`，或者 `application.yaml` 里：

  ```yaml
  halo:
    external-url: https://blog.example.com
  ```

没有设置，或者和 MomoBird 来源的网站地址不一致时，插件**不推送也不撤下任何公开文章**，并在「工具 → MomoBird」页面写明两边的地址，改好后下一次同步自动恢复。（已经不公开的文章，比如改成私有、移入回收站的，仍会照常撤下：撤下不需要地址。）

## 同步规则

一篇文章同时满足下面几条才会同步：

- 已发布，并且不是定时发布还没到时间的；
- 可见性为「公开」（内部、私有都不同步）；
- 不在回收站；
- 没有被排除。

**排除某一篇文章**：在文章设置的「元数据」里加一条 `momobird.ai/exclude`，值写 `true`。`true`、`yes`、`on`、`1`（不分大小写）都算排除；写成 `false` 或其他值、或者没有这条元数据，文章照常同步。

文章如何映射到 MomoBird：

- **文章编号**：对文章的 `metadata.name` 做 SHA-256，取前 52 位转成十进制数字（最多 16 位）。算法和 Hexo 插件完全一样。`metadata.name` 创建后不会变，改标题、改别名（slug）都不会让文章变成「新文章」。
- **标题**：文章标题，最多 255 个字符。
- **链接**：Halo 外部访问地址 + 文章的固定链接。
- **分类**：文章分类所在分类链的顶层分类的显示名，最多 64 个字符；没有分类时不发送。控制台知识页可以按分类筛选，问答助手也可以只回答某个分类。
- **正文**：文章发布版本的 HTML 转成纯文本，保留标题层级，代码块保留文字，去掉 `script`、`style`、`iframe`。
- **修改时间**：发布时间和最后修改时间里较晚的那个。
- **被插件隐藏的内容**：用「限制阅读」类插件（plugin-restricted-reading，需要 Halo 2.25 或更高）隐藏的部分，对应的文字不会发给 MomoBird，否则问答助手会把它说给任何人听。
- 每个请求超时 30 秒；网络错误和 5xx 自动重试 2 次，间隔 1 秒、3 秒。还失败的文章记进「待重试」列表。

## 什么时候同步

- **文章事件**：发布、修改、下线、删除、可见性变化。事件先进内存队列，2 秒内同一篇文章的多次事件合并成一次，由插件自己的单个后台线程按批推送。
- **元数据变化**：只改文章元数据（加上或去掉 `momobird.ai/exclude`，或者打开、关闭「限制阅读」的 `restrict.enabled`）时，Halo 不发文章事件。插件自己留意文章的每次变化，只要这两项和它上次读到的不一样，就像收到事件一样重新读这篇文章：几秒内撤下或推送，不用等全量对账。插件启用后到第一次全量对账（一分钟后）之间改的元数据，由这次对账处理。
- **全量对账**：插件启用（或 Halo 启动）一分钟后一次，之后每天凌晨 4 点（服务器时间）一次，以及后台页面上点「立即全量同步」时。把应同步的文章全部推送一遍（MomoBird 对没变的文章返回「未变」，不会重新向量化），MomoBird 上有、Halo 里没有的撤下。
- **重试**：被拒绝（比如内容有问题）和暂时没推送成功（比如网络错误）的文章会在下一次文章事件、每天的对账或手动点「重试失败项」时再推送。因套餐到期（402）没推送的文章**不在**重试列表里，续费后要点「立即全量同步」或等每天凌晨 4 点的对账补上。
- 没有设置连接密钥时，自动同步安静地跳过；手动同步会告诉你缺什么。
- 停用插件后，所有同步线程立即停止，不再向 MomoBird 发任何请求；重新启用后重新开始。

## 后台页面：工具 → MomoBird

Halo 后台「工具」里的 MomoBird 页面，给能管理插件的管理员（超级管理员、拥有「插件管理」权限的角色，以及被授予「MomoBird 同步管理」权限的角色）使用：

- **连接状态**：项目名、来源名和类型、套餐与到期时间、问答助手状态、站点地址检查结果、Halo 里应同步的篇数、MomoBird 上的篇数、上次同步的时间和结果。
- **按钮**：「测试连接」只看一眼状态，不同步；「立即全量同步」马上对账一次（耗时长时页面会自动轮询到结束）；清理保护拦下撤下时多出一个「确认撤下」；「重试失败项」把被拒绝和暂时没推送成功的文章再推一次（套餐到期没推送的文章不在其中，见下面「套餐到期」）。
- **失败列表**：文章标题、错误码和时间。

只有「插件查看」权限的用户看不到这个菜单，直接调用接口也会得到 403。要单独授权，可以在「用户 → 角色」里给角色勾选「MomoBird 同步管理」。

## 清理保护

为了防止一次出错的操作（比如数据库被换掉、文章没读全）把整个知识库清空，自动对账时遇到下面任一情况会**跳过全部撤下**，并在后台页面提示：

- Halo 里应同步的文章一篇都没有；
- 要撤下的文章超过 10 篇，并且超过 MomoBird 上总数的一半。

确认无误后，在「工具 → MomoBird」页面点「确认撤下」。

如果 MomoBird 上这个知识源的类型不是 `halo`（比如连错了 WordPress 或 Hexo 的来源），插件会提示，照常推送文章，但**不会自动撤下**任何文章：那些文章是别的平台推上去的，也需要在页面上点「确认撤下」才会执行。

文章被改成私有、移入回收站、取消发布、加上排除标记或永久删除时，那一篇会立刻撤下，不受清理保护限制。

## 问答助手和播客

- 在设置里打开问答助手后，插件通过 Halo 的页头扩展点在每个前台页面的 `<head>` 里加入：

  ```html
  <script src="https://momobird.atlaspaces.com/widget/loader.v1.js" data-project="<项目公开编号>" data-position="right" defer></script>
  ```

  插件每 10 分钟向 MomoBird 查询一次助手状态：项目下线、助手被关闭、来源停用、套餐到期时，脚本不再输出。渲染页面时只读缓存，不会因为 MomoBird 慢而拖慢你的站点。
- 设置里打开了助手时，第一次全量同步成功后，如果项目的网站接入还没上线，插件会自动开启一次。助手被你在控制台关闭或撤销后，插件不会自动重新开启。
- 打开播客播放器（默认开）后，会同步的文章页正文末尾会加一个不可见的占位元素 `<div class="momobird-podcast" ...>` 和播放器脚本 `https://momobird.atlaspaces.com/widget/podcast.v1.js`。播客在 MomoBird 控制台生成；文章没有播客时播放器什么也不显示。排除的文章、私有文章和草稿没有占位元素。

页面里只输出公开的项目编号、来源编号、文章编号和 API 地址，不带密钥。

## 套餐到期

试用或专业版到期后，MomoBird 不再接受新增和修改的文章（402）：插件停止推送，后台页面显示「套餐已到期」和这次没推送的篇数，这些文章不会进「失败列表」，「重试失败项」也不会推送它们：续费或开通后，点「立即全量同步」或等每天凌晨 4 点的对账就会补齐。**撤下照常执行**：改成私有、删除的文章仍然会从 MomoBird 撤下，不会在到期后继续被助手引用。到期后问答助手是否还显示，由 MomoBird 告知，插件在 10 分钟内跟随。

## 常见问题

**后台页面提示「站点地址不一致」，或者「外部访问地址还没有设置」。**
Halo 的外部访问地址和 MomoBird 来源的网站地址不同源。常见原因：一边有 `www` 一边没有；一边 http 一边 https；端口不同；Halo 里根本没设置（2.17 要用 `halo.external-url`，见上）。改成一致后重新同步。

**401 / 「连接密钥无效或已被吊销」。**
密钥复制错了、被重新生成或吊销，或者控制台里的来源已被删除。到控制台重新生成密钥，再由超级管理员在「插件 → MomoBird AI → 设置 → 连接」的「连接密钥」里更新（见上面「连接密钥存放在哪里」）。

**402 / 「套餐已到期」。**
见上面「套餐到期」。

**409 / 「这个知识源已在 MomoBird 控制台停用」。**
来源被停用了。到控制台重新启用后再同步。另有一种 409（`WIDGET_NOT_READY`）是第一次同步时文章还没建好索引，没有来得及开启问答助手，插件下一次对账会自动再试。

**为什么有些文章没有同步？**
草稿、定时发布还没到时间、私有或内部、在回收站、元数据里有 `momobird.ai/exclude: true`，或者文章还没有固定链接（Halo 还没生成，稍后会重试）。页面（独立页面）不同步。

**用了「限制阅读」之类的隐藏内容插件，被隐藏的部分会发给 MomoBird 吗？**
plugin-restricted-reading（Halo 2.25 或更高）隐藏的部分不会发送：开了限制的文章只发分隔标记之前的内容，没有分隔标记时整篇不发正文。其他通过别的方式（登录可见、回复可见）在渲染时才隐藏文字的插件，插件没法知道，这些文字会被当成正文同步；如果文章里有不想让助手引用的内容，请给这篇文章加上 `momobird.ai/exclude`。

**能不能先删掉一篇文章，过几天再加回来？**
不建议把删除当作临时手段；文章只是要改一改的话，直接改好即可，MomoBird 会更新原来那篇。分两种情况：

- **插件撤下的文章**（改成私有、移入回收站、取消发布、加上 `momobird.ai/exclude` 标记）：30 天内重新公开，会回到 MomoBird 里**原来的那篇文档**，之前生成的播客也还在。
- **在 Halo 里永久删除后重新创建的文章**：新文章有新的 `metadata.name`，在 MomoBird 里是**新文档**，播客需要重新生成。在 MomoBird 控制台里删掉的文档同理：之后再同步上来的是新文档，播客需要重新生成。

**Halo 里的文章改了别名（slug）或标题，会变成新文章吗？**
不会。文章编号来自 `metadata.name`，创建后不变。

**为什么日志里看不到什么？**
正常情况下插件很安静：启用时一行「[MomoBird] 同步服务已启动」，每次同步一行摘要。把 `ai.momobird` 的日志级别调到 DEBUG 才会打印每个收到的文章事件。

## 日志

所有日志统一带 `[MomoBird]` 前缀，不会出现连接密钥（连密钥前缀也不打印）。例如：

```
INFO  [MomoBird] 同步服务已启动：1 分钟后全量同步一次，之后每天 04:00 一次
INFO  [MomoBird] 全量同步：推送 3 篇，未变 0 篇，撤下 0 篇，失败 0 篇
```

## 开发

```bash
export JAVA_HOME=/path/to/jdk-17      # 默认的 java 可能更旧
./gradlew test                        # 单元测试
./gradlew build                       # 含后台页面（UI）的构建，产物在 build/libs
scripts/integration.sh                # 在真实的 Halo 2.17 和 2.27（Docker）上跑一遍，对本机的模拟服务，要几分钟，请放到后台运行
scripts/package.sh                    # 生成 dist/halo-momobird-ai-<版本>.jar 并检查包内文件、扫描密钥
```

`dev/mock-connect.js` 是 connect API 的本地替身，集成测试用它代替 MomoBird（可以在运行中切换 402、401、来源类型、站点地址）；集成测试里的 Halo 管理员账号和假密钥都只是本地测试值。控制台检查（检查 2 和 8.3）需要 Playwright 和一个 Chromium：

- `PLAYWRIGHT_DIR`：Playwright 包的目录（`node_modules/playwright`）；不设时按 Node 的常规方式找 `playwright`（当前目录、`ui/` 或仓库的 `node_modules`）。
- `PLAYWRIGHT_CHROMIUM`：Chromium（或 chrome-headless-shell）可执行文件的路径；不设时用 Playwright 自带的浏览器（`npx playwright install chromium`）。
- `SKIP_BROWSER=1`：跳过这两项检查，汇总里会打印 `SKIPPED`。

找不到 Playwright 或浏览器时脚本会说明缺什么并让这两项失败，不会悄悄跳过。`dev/`、`scripts/` 都不在发布的 jar 里。

## 安全说明

- 连接密钥只从插件设置所选的 Halo 密钥（Secret）读取，插件设置本身不含密钥；只有超级管理员能通过 Halo 的接口读到这个密钥。日志、错误信息、后台页面接口和前台页面里都不会出现它。
- 只发送公开文章的标题、链接、分类、修改时间和纯文本正文。
- 生产环境 Base URL 必须使用 HTTPS（只有 `localhost`、`127.0.0.1`、`[::1]` 和 `host.docker.internal` 允许 http，供本地联调）。
